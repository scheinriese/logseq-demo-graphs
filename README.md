# Logseq demo graphs

**Graphs last updated: 11 November 2026 · Latest journal day: 11 November 2026.**

Realistic sample graphs for exploring and learning Logseq, testing features and
plugins, or creating tutorials and screen recordings without using personal notes.

## Choose a graph

- [Writer](writer/): manuscripts, reading, writing projects and daily work.
- [Student](student/): courses, study notes, assignments and everyday planning.
- [Academic](academic/): research, literature, people and journals.
- [Operator](operator/): projects, meetings, decisions and operational work.

Try following links between pages, exploring journal entries, or experimenting
with queries and plugins. For recordings, choose the persona that fits your
example and use the latest journal day above to plan your demonstration.

## Open a copy

1. Clone or download this repository, then copy **one graph folder** to a fresh
   local graph directory, keeping its `db.sqlite` and any `assets/` together.
2. With Logseq closed, put that copy in your Logseq graphs location.
3. Start Logseq and select the copied graph from the graph menu.

Use a DB-capable Logseq build supporting schema **65.40**; compatibility with
arbitrary stable or Markdown-only builds has not been verified.

Always work on a copy: opening a graph can change it, and you should never
overwrite your own notes. A repository download contains four separate graphs,
not one graph to import.
