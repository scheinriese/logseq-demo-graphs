# Finished graph collection

This repository contains ready-to-open SQLite graphs and referenced assets, not
generation inputs or tools. Preserve graph content, addresses, names, UUIDs,
image bytes and notices exactly. Academic is the public label for researcher-demo.

Open/check databases only on disposable copies; canonical outputs must not gain
WAL/SHM, locks, caches or indexes. Record immutable source/tool/runtime pins and
released-through dates; exclude future pending journals. Validate per-file hashes,
SQLite integrity, runtime schema/importer compatibility and attachment parity.

Keep source history/refs recoverable until generator migration is accepted.
No workflow, live pipeline change, new license, release publication, visibility
change or collaborator invitation without separate approval. Never put credentials
or private account/local-path metadata in outputs. Use the required privacy audit
before remote review delivery. Daily binary refreshes belong in releases, not
automatic daily Git commits.
